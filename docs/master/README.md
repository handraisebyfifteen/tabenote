# マスターデータ(アプリには同梱しない)

`tabenote_foods_master.json` は、備考(中医学上の注意・禁忌)とページ参照を含む**変換前の完全版データ**。

2026-08-17 の方針決定により、アプリに同梱する `src/data/tabenote_foods.json` からは
以下を取り除いた(著作権リスクの除染。経緯は依頼者との協議記録を参照):

- `note` の「※」以降(特定書籍に由来する中医学上の注意・禁忌・調理による性の変化)
- `page`(単一書籍へのページ参照)

残したのは事実データのみ: 性・味・帰経・分類、および別名・漢字名(生物学上・言語上の事実)。

このマスターは **v2 で日本中医食養学会から許諾が得られた場合に、公認データとして
復元するための保管**である。許諾なしにアプリへ再同梱しないこと。

データを更新するときは、マスターを直してから変換スクリプトで同梱版を作り直すのではなく、
同梱版(事実データ)を直接編集してよい。マスターは凍結保管。
