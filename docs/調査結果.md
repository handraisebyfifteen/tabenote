# 申請準備 Phase 1 — 調査結果(2026-08-17)

「tabenote-申請準備-指示書.md」Phase 1 の調査結果。プライバシーポリシーの根拠になるため、
**内容が実態と合っているか、依頼者の確認を得てから Phase 2 に進む。**

## 調査結果サマリ

- スタック: Expo SDK 57 / TypeScript / Expo Router(4タブ + モーダル2枚)
- 課金: react-native-purchases **10.7.1 導入済み**(ペイウォール・復元・設定画面の導線も実装済み。ただし「月額+年額の2プラン選択UI」なので指示書の1プラン構成に合わせて作り直しが必要)
- 収集データ: **個人情報の収集なし。** ログイン・アカウント機能なし。メールアドレス等を集める機能なし
- 保存先: **すべて端末内(AsyncStorage)。** サーバーへの保存なし
- 外部SDK: RevenueCat のみ(解析・広告・クラッシュレポート・プッシュ通知はすべて無し)
- 権限: **一切要求しない**(カメラ・写真・位置情報・通知いずれも無し)
- 写真アップロード機能: なし
- 設定画面: あり(`src/app/(tabs)/settings.tsx`)。課金/復元の行も実装済み

### デザイントークン

`src/constants/theme.ts`(Colors / Fonts / Spacing)。ライト・ダーク両対応。
共通コンポーネントは `src/components/`(五角形チャート・食材タイルなど)。

### ユーザーデータの内訳(すべて端末内・AsyncStorage)

| データ | 内容 |
|---|---|
| お気に入り(★) | 食材IDの配列 |
| メモ | 食材ごとの自由記述(ユーザーが書く) |
| 保存した組み合わせ | 名前・食材ID・メモ・日付 |
| 選択履歴 | 食材ごとの選択回数(よく使う欄の自動昇格用) |
| 言語設定 | ja / en |

エクスポート機能あり(OSの共有シートでJSONを書き出す。ユーザー操作でのみ動く)。

### 外部に出ていくデータ

1. **RevenueCat**(課金を有効にした場合)
   - 匿名の app user ID、購入レシート情報。クレジットカード番号は Apple が処理し、開発者・RevenueCat には渡らない
2. **AI献立提案**(自前の Cloudflare Worker 経由 → Anthropic API)
   - 送るもの: 選んだ食材名・季節・味の情報・言語・匿名の app user ID
   - 個人情報は含まない
   - **現状は未接続**(`AI_PROXY_URL` が空・UIにボタンなし)。v1.0 に載せるかは要判断(下記「食い違い3」)

上記以外の通信は無い(解析・広告・トラッキングSDKは不使用)。

## 指示書と実態の食い違い(要確認)

### 食い違い1: Bundle ID

- 指示書: `app.tabenote`(App Store Connect のレコードもこれで作成済みとのこと)
- リポジトリ(`app.json`): `app.tabenote.main`(iOS / Android とも)

どちらかに揃える必要がある。ビルド未アップロードなのでどちらの変更もまだ簡単。

### 食い違い2: 課金モデル

- 指示書: 「課金しないと何も使えない構成(ハードペイウォール)」「月額 $9.99 の1本のみ」
- 実装と設計書(design_doc_rev4 7章): 「無料=五角形・手帳 / 有料=AIの献立提案」「月額+年額、1ヶ月無料トライアル」

現状の実装は**無料でほぼ全機能が使える**。どちらのモデルで行くかで、ペイウォールの文言・
App Store の説明文・審査リスク(Guideline 4.2)対策・プライバシーポリシーの書き方まで全部変わる。

### 食い違い3: 売り物(AI献立提案)が未接続

サブスクで解放される機能=AI献立提案は、中継サーバー(workers/ai-proxy)は実装済みだが
**未デプロイで、アプリのUIにも組み込まれていない**。このまま提出すると
「購読しても何も変わらないアプリ」になり、Guideline 2.1 / 3.1.2 で確実に落ちる。
v1.0 に AI提案UIを載せる(Workerのデプロイ込み)必要がある。

### 補足: トライアル無しと Shipaton

設計書は Shipaton 2026 への提出を前提にしており、その要件は「無料トライアル **または**
審査員用プロモコード」。指示書どおりトライアル無しで行く場合は、オファーコード
(プロモコード)で要件を満たす必要がある。

## 決定事項(2026-08-17 依頼者確認済み)

1. **課金モデル: 全機能有料**(ハードペイウォール)。月額プラン1本($9.99)。トライアル・年額なし。
   既存の「無料=五角形・手帳」の線引きは廃止し、アプリ全体を購読の後ろに置く
2. **Bundle ID: `app.tabenote.main` に統一**(リポジトリ側を維持)。
   依頼者側作業: Developer ポータルで App ID `app.tabenote.main` を登録(In-App Purchase 有効)
   → App Store Connect のアプリ情報で Bundle ID を変更 → RevenueCat にも同じ値を入力
3. **AI献立提案を v1.0 に搭載**(Worker のデプロイ + アドバイス画面へのUI追加)
4. Shipaton の「無料トライアル or プロモコード」要件は、トライアル無しのため
   **オファーコード(審査員用プロモコード)** で満たす
