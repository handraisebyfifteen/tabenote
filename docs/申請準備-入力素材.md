## Step 6. App Privacy と年齢レーティング

### App Privacy(ASC →「Appのプライバシー」)

質問にはこの通りに答える:

- 「このAppからデータを収集していますか?」→ **はい**
- **購入 → 購入履歴**: 収集する
  - 用途: **アプリの機能**、**アナリティクス**
  - ユーザーの身元に紐付け: **いいえ**(匿名の app user ID のみ)
  - トラッキングに使用: **いいえ**
- (保守的に申告する場合)**ユーザーコンテンツ → その他のユーザーコンテンツ**: 収集する
  - 根拠: AI献立提案で選択食材名・季節・言語を自前サーバー経由で Anthropic API に送信するため
  - 用途: **アプリの機能** / 紐付け: **いいえ** / トラッキング: **いいえ**
- それ以外の項目(位置情報・連絡先・識別子など)はすべて「収集しない」
- 「トラッキングに使用しますか」系の質問はすべて **いいえ**(広告・解析SDKなし)

プライバシーポリシーURL: `https://tabenote.app/privacy`

### 年齢レーティング(2025年刷新版の質問票)

- 暴力・性的内容・ギャンブル・ホラー・薬物など: すべて **なし**
- **医療・治療情報: なし**(効能・診断・治療・症状を一切扱わない。表示は伝統分類の事実データのみで、アプリ内に免責と「医療専門家に相談」の記載あり)
- ユーザー生成コンテンツの共有・交流機能: **なし**(メモは端末内のみ・共有機能なし)
- 想定結果: **4+**。「健康・ウェルネスの助言を提供するか」という趣旨の質問に「はい」と答えると 13+ になり得るが、本アプリは助言をしない設計なので該当しない。質問文には正直に答えること(レーティングが 13+ になっても提出には支障ない)。

## Step 7. 配信国と EU DSA

**✅ 決定(2026-08-17): 初回は EU/EEA 加盟国を配信国から外す。**トレーダー申告(住所・電話の検証と EU 商品ページへの公開)はしない。EU 展開したくなったら、そのとき ASC で trader 申告 → 配信国に追加すればよい(公開後いつでも可能)。

ASC での操作手順:

1. ASC → アプリ →「価格および配信状況」→「配信可能な国または地域」を編集
2. 「すべての国または地域を選択」を**使わず**、EU/EEA の 30 か国(EU 27 + アイスランド・ノルウェー・リヒテンシュタイン)のチェックを外す。英国(UK)とスイスは EU/EEA ではないので**残してよい**
3. **日本・米国が含まれていることを必ず確認**(審査は米国の sandbox で行われる)
4. 「App配信ステータス」に DSA のトレーダー質問が出た場合は「トレーダーではない/EU で配信しない」側を選ぶ(EU を外していれば申告不要のまま提出できる)
