# 別名フィールド(note)の分離 — 対象一覧

`src/data/tabenote_foods.json` の `note` は、別名・漢字名と「※」以降の中医学的な記述が同居していた。
後者は医学上のエビデンスに乏しいため画面から外し、`caution` フィールドに退避した(データからは消していない)。
食品安全上の事実だけは `safety` として残し、別名とは別のラベルで表示する。

| | 件数 |
|---|---|
| 全食材 | 438 |
| note に「※」を含んでいた | 92 |
| `safety` として表示を残した | 4 |
| 別名(`note`)に戻した | 5 |
| `caution` に退避した(非表示) | 86 |

## 1. 残したもの — `safety`(画面に「安全上の注意」として表示)

中医学の禁忌ではなく、一般に確立した食品安全の事実。

| 食材 | 表示する文 | 元の記述 |
|---|---|---|
| きんしんさい | 生は小毒なので加熱し多食を控える | 生は小毒なので加熱し多食を控える。禁忌:皮膚掻痒の者 |
| ぎんなん | 小毒あり。多量摂取と小児は注意 | 注意:小毒あり。多量摂取と小児。生食は駆虫作用あり |
| ふぐ | 肝臓、卵巣は猛毒 | 肝臓、卵巣は猛毒 |
| さんしょう(中国) | 小毒あり | 小毒。注意:陰虚火旺の者・妊婦。皮に局所麻酔及び鎮痛作用 |

うち3件は元の文から表示用に整えた(ぎんなん「小毒あり。多量摂取と小児」→「…小児は注意」、さんしょう「小毒。」→「小毒あり」、きんしんさいは冒頭の一文のみ抜き出し)。残りは退避側に回した。

## 2. きじにく — 非表示のまま(2026-08-24 決定)

| 食材 | 記述 | 扱い |
|---|---|---|
| きじにく | 古書では微寒。春夏に捕穫したものは微毒あり | 退避(非表示) |

「微毒あり」は毒性の記述だが、「古書では」という伝聞の枠の中にあり、確立した食品安全の事実とは言いにくい。きじにく自体が一般的な食材ではなく、医学上のエビデンスもないため、`safety` には移さず退避のままとする。
`src/logic/__tests__/data.test.ts` の「きじにくの「微毒」は退避したまま」で固定した。

## 3. 別名に戻した5件(2026-08-24)

退避した中に、中医学ではなく単なる別名・和名の情報が混じっていた。この5件は `caution` から `note` に戻し、画面の「別名」に出している(`caution` は空にした)。検索でも引けるようになった。

| 食材 | 戻したあとの別名 | 元の別名 | 退避していた記述 |
|---|---|---|---|
| むーるがい | 淡菜・ムール貝・ムラサキ貝 | 淡菜・ムール貝 | ムラサキ貝の別名 |
| まいかいか | 玫瑰花・はまなす | 玫瑰花 | 和名はまはなす |
| あまざけ | 酒醸(米麹の甘酒) | 酒醸 | 米麹の甘酒 |
| ずいき | 芋頭茎(乾かした物がいもがら) | 芋頭茎 | 乾かした物がいもがら |
| はぶちゃ | ハブ茶(決明子の成熟種子を炒ったもの) | ハブ茶 | 決明子の成熟種子を炒ったものがハブ茶 |

書き方は、別名そのもの(ムラサキ貝・はまなす)は「・」で並べ、別名の説明にあたるものは括弧で添える、で揃えた。原文に手を入れたのは次の2か所。**戻す前の姿は上の表に残してあるので、気に入らなければ元に戻せる。**

- **まいかいか**: 原文は「和名はまはなす」。玫瑰花(ハマナス / Rosa rugosa)の和名は「はまなす」で、「和名は」+「はまなす」の `は` が1つ落ちた誤記と判断し、別名として「はまなす」を採った。原文どおり「はまはなす」だと検索でも引けない。
- **はぶちゃ**: 原文は「決明子の成熟種子を炒ったものがハブ茶」。別名がすでに「ハブ茶」なので、末尾の「がハブ茶」は重複として落とした。

`src/logic/__tests__/data.test.ts` の「別名に戻した5件は退避側から消え、別名として引ける」で固定した。
