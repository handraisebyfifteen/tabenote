# デモモード(Devpost 提出用デモ動画の自動操作)

楽曲(BPM 123・4/4)に合わせてアプリを自動操作する撮影用モード。
仕様は「デモモード仕様書 v2」。本番ビルドでは `EXPO_PUBLIC_DEMO` を
設定しないため、デモ関連のコードは一切実行されない。

## 起動

開発中の確認:

```bash
EXPO_PUBLIC_DEMO=1 npx expo start
```

本番の撮影(開発モードより滑らかで、BPM 123 の台本がコマ落ちしにくい):

```sh
npx eas build -p ios --profile demo    # simulator 継承のリリースビルド
# 完了後、ビルドページの .tar.gz を落として展開
xcrun simctl boot "iPhone 16 Pro" && open -a Simulator
xcrun simctl install booted /path/to/tabenote.app
xcrun simctl launch booted app.tabenote.main
xcrun simctl io booted recordVideo --codec=h264 demo.mov   # Ctrl+C で停止
```

## 画面の操作(DEMO_MODE のときだけ出る)

- 右下 **▶**: カウントイン(4拍 = 1小節 = 1951ms)→ 台本を実行。
  左上に4つの点のインジケータが出て、▶を押した瞬間に1拍目が点く。
  1拍ごとに進み、4拍目の直後(= 楽曲の 0:00.00)に消える。
  編集ではこの4拍を頭から切り落とし、最初の点灯フレームを基準に曲と合わせる。
- 右下 **■**: 停止。タイマーを全部止めて初期状態に戻す。アプリを再起動せずに
  もう一度▶から撮り直せる。
  なお、季節モーダル(5〜7小節)とアドバイス(24〜27小節)はネイティブ提示で
  この操作 UI より前面に出るため、その約10秒だけは■・⇣が押せない。
  止めたいときはモーダルが下りるのを待つ。
- 右下 **⇣**: 手帳・図鑑・解説をなめらかに1段階スクロール(撮影中に手で押す用)。

## 撮影前の準備

- アプリの言語を **英語** にする(動画は英語版。検索も英語名 "bitter" で走る)。
- 手帳(組み合わせ)に見せられる保存データを数件作っておく(27小節で映る)。
- 端末の「視差効果を減らす」を **オフ** に(オンだと点灯・ポップの演出が消える)。
- 課金ゲートは `EXPO_PUBLIC_SKIP_PAYWALL=1` で消す(`.env.local`、または
  eas.json の `demo` プロファイル)。この抜け道は `__DEV__ || !Device.isDevice` の
  ときだけ効く(`src/lib/billing.ts`)ので、**実機のリリースビルドでは無効**。
  RC のキーが入ったビルドを実機に入れるとゲートを抜けられず撮影できない。
  撮影は**シミュレータ**で行う。

## 台本(src/demo/script.ts)

時刻はすべて▶押下からの絶対値で登録される(相対連鎖は禁止。`src/demo/driver.ts`)。
カウントイン中はスプラッシュを被せ、その下で組み合わせ・手帳をマウントして
初期状態(★= あじ)を作る。

使う食材(id は `tabenote_foods.json` の実測値):

| 用途 | 名前 | id | 性 | 味 |
|---|---|---|---|---|
| ★の初期値 | あじ | `f15820a` | 温 | 甘・鹹 |
| 差し替え先 | ぶり | `f404349` | 温 | 甘・酸 |
| 検索で追加 | にがうり | `f9fd7db` | 寒 | 苦 |

検索語は "bitter"(Bitter melon)。3文字 `bit` で2件(にがうり・うさぎにく)、
4文字 `bitt` で一意になる。

## 撮影時に調整する定数(src/demo/config.ts)

| 定数 | 意味 | 既定 |
|---|---|---|
| `LEAD.modalOpen` / `modalClose` | 季節モーダルの fade ぶんの先行呼び出し | 300ms |
| `LEAD.adviceDismiss` | アドバイスを閉じて手帳が全面に出るまで | 500ms |
| `DEMO_TYPE_MODE` | 検索入力 `per-char` / `instant`(描画が詰まったら instant) | per-char |
| `TYPE_INTERVAL_MS` | 1文字あたりの間隔 | 120ms |
| `DEMO_SEASON` | 季節モーダルで選ぶ季節(今日の季節と別のものに) | winter |
| `DEMO_CHIP_STEP_PX` | カテゴリーチップ1個ぶんの横スクロール量 | 66px |
| `SCROLL_STEP_PX` / `SCROLL_STEP_MS` | ⇣ボタンの1段階 | 320px / 700ms |

スクロールの台本上の既定(29・33・35・39小節)は `script.ts` 内の数値を直す。

## 実装のかたち

- `src/demo/registry.ts` — 画面側が DEMO_MODE のときだけ、自分の state を動かす
  ハンドラを「接頭辞 + ref」で登録する。台本は `demoCall('combine.tapTile', id)` の
  ように呼ぶ。音・点灯は手でタップしたときと同じ関数を通る。
- タイルの選択は実装の語彙どおり2タップ(1回目 = カーソル、2回目 = 決定)。
  仕様書の「決定(1回目)」はぶりタイルへの2タップ目、「決定(2回目)」は
  画面下の決定ボタン(→ アドバイス)に割り当てた。
- ぶりは魚介分類の60番台で画面外になるため、デモ中だけグリッド先頭に
  繰り上げる(`demoPin`。DEMO_MODE でなければ経路に入らない)。
- スプラッシュの再表示は `SplashWordmark` に `minTotalMs`(合計表示時間の下限)を
  追加し、余韻を引き延ばす方式。冒頭は幕が引き切る瞬間が2小節2拍目に当たる長さ、
  49小節の締めは文字が出そろった姿のままカットまで留め置く長さを渡す。
