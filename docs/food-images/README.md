## 列の意味

- **No.** — 全体通し番号(1〜438)
- **file (id)** — `foods.ts` の固定 ID。生成画像のファイル名にそのまま使う(例: `f254f72.png`)。ID はメモ・お気に入りの紐付けキーなので変更しない
- **日本語名 / English** — 被写体の特定用。英語名は `src/data/foodNamesEn.ts` 由来(AI 下訳)
- **分類** — 15分類ラベル
- **補足(note)** — 漢名・別名・注意書き。同名で紛らわしいものの識別に使う

## 生成時の指定(共通)

現状のタイルは絵文字プレースホルダ(`src/data/foodEmoji.ts`)なので、差し替え前提で揃える:

- 正方形 1:1、被写体を中央に、余白は均等
- 背景は単色または透過(タイルの背景色に載せるため)
- 1品につき 1 種類の食材のみ。皿・カトラリー・手・文字は入れない
- 全 438 件で画風・光源・彩度を統一する(バッチをまたいでもブレさせない)

## 注意点

- 同じ食材の状態違いが別 ID で入っている(例: `ゆず` と `ゆず(皮)`、`(生)/(乾)` など)。note を見て描き分ける
- `nature` が空の「参照のみ項目」が 5 件あり、アプリ上では選択不可。画像は不要なら飛ばしてよい
- 英語名が未整備だった 7 件はこのリスト内で補記済み(`foodNamesEn.ts` 側は未反映)
